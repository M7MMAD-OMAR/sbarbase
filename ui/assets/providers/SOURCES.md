# Provider icons

One monochrome brand mark per sign-in provider, kept here as local SVG files and bundled into the console. Nothing is loaded from the network at run time.

Source: the [Simple Icons](https://simpleicons.org) project, version 13.21.0, whose icon files are released under CC0 1.0 (public domain dedication, [licence](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)). The files are unchanged except for a `fill` attribute that sets the brand colour Simple Icons lists for the mark.

The marks are trademarks of their owners. CC0 covers the files, not the trademarks: they identify the provider on its own sign-in row and are not used to suggest endorsement. Each owner publishes brand guidelines that apply to larger or different uses.
