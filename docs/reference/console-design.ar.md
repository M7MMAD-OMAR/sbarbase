# تصميم لوحة الإدارة

آخر تحديث 2026-11-13. يصف هذا المرجع الواجهة الحاليّة. حُذفت روابط المعاينات المؤقّتة وتعليمات العروض المنتهية. يحدّد [مرجع الحالة](status.ar.md) النسخة المثبّتة، ويبيّن [مرجع الجاهزيّة](deployment-readiness.ar.md) ما بقي من التحقق.

## الأسطح وعناصر التحكم

تتّبع لوحة Sbarbase لغة Supabase البصريّة، باستخدام ألوان دلاليّة للوضعين الفاتح والداكن في `ui/style.css` وعناصر مشتركة في `ui/components.tsx`. تستخدم اللوحة React وCSS، ولا تثبّت مكتبة مكوّنات React الخاصّة بـ Supabase. أمّا Studio الأصليّ فيعمل منفصلًا كصفحة كاملة. يبقى إسناد المصدر في `NOTICE`.

تعتمد الحقول والأزرار والبطاقات والجداول والتنبيهات والتبويبات على أسطح ملوّنة تميّز الارتفاع دون حواف زخرفية. وللعنصر المختار لون سطح مختلف. ويبقى مؤشر التركيز ظاهرًا عند استخدام لوحة المفاتيح، بما في ذلك الخيارات داخل القوائم. وتحتفظ إجراءات الحذف بتسميتها وطلب التأكيد.

تستخدم قوائم الاختيار تنسيقًا موحّدًا يتّبع ألوان الواجهة. وفي المتصفّحات الداعمة، تتيح `appearance: base-select` قائمة فوق محتوى الصفحة مع علامة للخيار المحدّد وقائمة ذات ارتفاع محدود يمكن تمرير محتواها والتفاف للأسماء الطويلة. وتحتفظ المتصفّحات الأخرى بقوائمها الأصليّة وألوان الخيارات المناسبة للثيم. ويستخدم وضع الألوان القسريّة أسطحًا متباينة من ألوان النظام. يتّبع محدّد مساحة Studio المستقلّ الأسلوب نفسه، وتحتفظ مكوّنات Studio الأصليّ بتنسيقها الخاصّ.

## التنقّل

يملأ الشريط الجانبيّ ارتفاع النافذة على الكمبيوتر، ويمكن تمرير روابطه وحدها. تبقى محدّدات مساحة العمل وأزرار التذييل ظاهرة. ويفصل تخطيط الهاتف بين المحدّدات ويحافظ على الوصول إلى إجراءات التذييل.

للمؤسسة والمشروع والبيئة محدّدات مباشرة. تُلغى الطلبات عند تغيّر النطاق، ويُتحقق من نطاق الردّ قبل استخدامه. واختيار مشروع يمسح البيئة السابقة. تُحمّل مساحة الاتصال داخل المحتوى الرئيسيّ، مع بقاء القائمة الجانبيّة ظاهرة وتوفير الاستعادة عند فشل التحميل.

تحتاج مغادرة مسوّدة دالة Edge غير منشورة إلى تأكيد عند تبديل المشروع أو البيئة أو التنقّل من هيكل اللوحة. وتحتفظ النماذج الأخرى بطريقة الحفظ الخاصّة بها؛ لا يشمل هذا السلوك جميع النماذج غير المحفوظة.

## هويّة التبويب وStudio

يحمل عنوان تبويب اللوحة اسم المشروع والبيئة المختارة. ويضيف Studio اسم المشروع والبيئة قبل عنوان صفحته، مع اسم عرض في معامل `workspace` بالرابط. تُستخدم الأسماء كنصّ، وتُحذف محارف التحكم وتنسيق اتجاه النص، ويُطبّع اسم الرابط ويُرمّز بأمان. لا يمنح الاسم صلاحيّة ولا يختار قاعدة بيانات أخرى.

يبقى مضيف البيئة والجلسة الموقّعة أساسًا للتوجيه والوصول. ويُحذف معامل العرض قبل تمرير طلبات المشروع إلى Studio. يتطلّب التبديل صلاحيّة حاليّة للمصدر والهدف، وطلب POST من المصدر نفسه، ومدخلات محدودة، ووجهة عاملة. تتّبع إضافة العنوان تنقّل Studio الأصليّ دون استبداله. وقد تمنعها سياسة CSP المقيّدة، ولا يخفّف النظام تلك السياسة لتشغيل الإضافة.

## لقطة الخادم

يقتصر `GET /management/v1/server` على مشغّلي التثبيت. وتُحفظ النتيجة مؤقّتًا لمدّة خمس ثوان، مع `Cache-Control: no-store`. تعرض اللقطة عدادات النظام للمعالج والذاكرة والمبادلة ومدّة التشغيل ونظام الملفات. ولا تقيس سعة الحمل ولا توفّر خدمة مقاييس Supabase المستضافة. وتظهر العدادات غير المتاحة على أنّها غير متاحة. ولأدوات المراقبة الخارجيّة متطلّبات دخول وتشغيل مستقلّة.

## التحقق

شغّل `bun run typecheck:ui` و`bun run typecheck:control` و`bun run build:ui`. يستخدم فحص المتصفّح المعزول `lab/project-workflow-browser.ts` إعداد Playwright المحلّيّ ومتصفّح Chromium المتاح، ويمكن تحديد مساره عبر `SBAR_BROWSER_EXECUTABLE`. ويغطي التبديل والمسوّدات والاستعادة والمظهرين وتمرير القائمة وتخطيط الهاتف. ويسجّل [تقرير التحديث](../evidence/server-console-2026-11-13.json) فحص اسم التبويب والرابط في Studio الفعليّ على خادم المالك. لا يثبت عدد الاختبارات أو لقطة منفردة قبول جميع مسارات الإنتاج.
