# تصميم لوحة الإدارة ومعاينة Studio المحلية

آخر تحديث 2026-10-06. يسجل هذا المرجع التنقل والعناصر الصغيرة ومعاينة Studio المؤقتة. لا يمنح موافقة للنشر الإنتاجي. راجع [جاهزية النشر](deployment-readiness.ar.md).

## أنماط Supabase الصغيرة

تكيّف اللوحة أنماط [قياسات مكتبة Supabase](https://github.com/supabase/supabase/blob/master/packages/ui/src/lib/constants.ts) و[الأزرار](https://github.com/supabase/supabase/blob/master/packages/ui/src/components/Button/Button.tsx) و[الشارات](https://github.com/supabase/supabase/blob/master/packages/ui/src/components/shadcn/ui/badge.tsx). تعلن [حزمة الواجهة](https://github.com/supabase/supabase/blob/master/packages/ui/package.json) ترخيص MIT. طبّقنا القياسات والأنماط في CSS المحلي الحالي، ولم نثبت أو ننسخ الحزمة كاملة.

تستخدم واجهة الكمبيوتر قياس الزر الصغير 26px والحقل 34px وأيقونات 14px وزوايا 6px وحدوداً هادئة. شارات الحالة صغيرة مع حدود وألوان دلالية. تبقى عناصر الهاتف بارتفاع 34px على الأقل. تبقى مؤشرات التركيز وأخطاء الحقول والقوائم الأصلية وخيارات الوضع الفاتح والداكن متاحة.

تظهر المشاريع كبطاقات، وللفريق وإعدادات المؤسسة عناصر منفصلة في القائمة الجانبية. تنقسم صفحة البيئة إلى النظرة العامة وStudio والمصادقة والخدمات والاستهلاك ومفاتيح API. تُفك الأقسام غير المحددة لإيقاف طلباتها واستطلاعها الدوري. الانتقال بين الأقسام يتخلى عن المسودات غير المحفوظة داخل نماذجها الفرعية؛ إعادة المحاولة في القسم نفسه تحفظ القيم. إذا أزالت الصلاحيات القسم المحدد يعود العرض إلى النظرة العامة.

## التنقل داخل مساحة Studio

يعرض شريط صغير المنظمة والمشروع والبيئة فوق Studio الأصلية ضمن iframe من المصدر نفسه. تبقى صورة المورّد وقاعدة البيانات ومسارات API كما هي. يسمح الوكيل بتضمين صفحات HTML من المضيف نفسه فقط، ويحفظ قيود CSP الأخرى. يفتح رابط Studio من لوحة الإدارة هذه المساحة تلقائياً. يطلب تغيير المنظمة أو المشروع لقطة بيانات واحدة ضمن الصلاحيات، ويستخدم تغيير البيئة القائمة المحمّلة. لا يوجد استطلاع دوري للتنقل ولا تشغيل تلقائي للخدمات.

تظهر فقط المنظمات التي يكون فيها المستخدم مالكاً أو مديراً. تعيد معاملة بيانات التنقل التحقق من صلاحية Studio الحالية. يتطلب التبديل طلب POST من المصدر نفسه تماماً، ومدخلات محدودة، وتحققاً جديداً من صلاحيات المصدر والهدف، وخدمة هدف عاملة. يصدر النظام تذكرة قصيرة العمر مرتبطة ببيئة الهدف وينتقل إلى مضيفها، مع إبقاء ملفات تعريف الارتباط منفصلة لكل مضيف وحفظ عنوان لوحة الإدارة الموثوق. تبقى البيئات غير المتاحة معطلة. يخفي الاختيار المعلّق المحرر الحالي حتى يعود المستخدم أو يفتح الهدف صراحة.

تحتوي المعاينة المحلية على http://127.0.0.1:8790/__sbarbase/workspace قاعدة فعلية واحدة، Sbar Shop / Production. تأتي أسماء المنظمات والمشاريع الأخرى من نموذج لوحة الإدارة ولا تفتح قاعدة فعلية ثانية. فُحص تبديل التذاكر بين المضيفين بصورة منفصلة باستخدام نموذج متصفح، وليس تثبيتاً فعلياً ثانياً.

## لقطة الخادم والمراقبة الكاملة

يمكن لمشغّل التثبيت طلب GET /management/v1/server. يتحقق كل طلب من الهوية ومن صلاحية المشغّل قبل قراءة التخزين المؤقت الكسول الذي يستمر خمس ثوان. لا يمكن للمستخدمين الآخرين جمع هذه العدادات. تحمل الردود Cache-Control: no-store.

تعرض البطاقات أنوية المعالج ومتوسط الحمل ومدة التشغيل والذاكرة والمبادلة وسعة نظام الملفات المتاح للتطبيق. قد تتضمن العدادات قيماً عامة للمضيف حتى عندما يعمل التطبيق داخل حاوية. لا تقيس حدود cgroup أو سجل Docker أو أداء قاعدة البيانات. تبقى العدادات المفقودة أو غير المتسقة غير متاحة. التحديث يدوي.

[Beszel](https://beszel.dev/guide/what-is-beszel) مراقب مستقل بترخيص MIT لسجل استهلاك المضيف وحاويات Docker والتنبيهات. توفر اللوحة رابط دليل إعداده. لم نثبته أو نربط تسجيل دخوله بهذا التغيير. استخدم حساب إدارة خاصاً ومستقلاً، ولا تضع رموز خدمة Sbarbase في روابط المراقبة. واجهة [Supabase Metrics API](https://supabase.com/docs/guides/observability/metrics) المستضافة غير متاحة للتثبيت الذاتي.

## حدود العرض المحلي

تستخدم لوحة الإدارة على http://127.0.0.1:8787 حساباً نموذجياً معلناً داخل الذاكرة. ليس تسجيل دخول إنتاجياً عاملاً. يفتح Sbar Shop / Production وحده Studio الأصلية المنفصلة على http://127.0.0.1:8790/__sbarbase/workspace.

تستخدم Studio قاعدة PostgreSQL تجريبية فعلية اسمها sbarbase_preview، تحتوي public.preview_tasks وصفّين نموذجيين. تحققنا من تحميل الجدول وتنفيذ استعلام العد من واجهة Studio نفسها. تعمل صور Studio وpostgres-meta الأصلية المثبتة بالملخص والموجودة محلياً مع تهيئة PostgreSQL مستقلة ومؤقتة. لا يثبت ذلك مسار التجهيز الكامل أو الإعداد الأصلي أو الترحيل في التطبيق.

لا تعمل Auth أو REST أو Storage أو Realtime أو Functions أو Logs في هذا العرض المحلي. فحوص المستشار غير متاحة دون التهيئة الأصلية الكاملة. تستخدم الاستعلامات المحفوظة مجلداً مؤقتاً خاصاً. لم نربط بيانات محفوظة للتطبيق أو حاويات مشاريع أخرى.

تستخدم الحاويات الثلاث المملوكة شبكة داخلية وجذور ملفات للقراءة فقط وتخزيناً مؤقتاً خاصاً، دون مجلدات مضيف أو مقبس Docker، مع سجلات محدودة ودون مبادلة للحاويات. مجموع حدود الذاكرة 1792 MiB ومجموع حدود المعالج نواة واحدة. يحذف المتحكم موارده وحدها بعد ساعتين أو قبل ذلك إذا انخفضت ذاكرة المضيف المتاحة عن 2 GiB. تختفي الجداول والاستعلامات المحفوظة عند انتهاء العرض. الرابط محلي فقط ولا يتطلب حساب معاينة، ويجب ألا يُعرض للعموم.

## نطاق التحقق

فُحصت اللوحة بمجموعة اختبارات Bun الحالية وفحص أنواع الواجهة وبنائها وفحوص اللغتين والروابط والمراجع ومسارات المتصفح. تشمل فحوص المتصفح التحقق من الحقول وإعادة المحاولة والتنقل المنفصل وتبديل المؤسسات وعدم تجاوز عرض الهاتف والعدادات الفعلية. للجداول وSQL في Studio الأصلية فحص متصفح منفصل. ما زال قبول التثبيت الكامل وجاهزية الإنتاج مفتوحين.

نجح التحقق من مساحة التنقل في 362 اختبار Bun وفحص أنواع الواجهة وفحص أنواع محدد لمصادر التطبيق واختبارات التنقل الجديدة. ما زال فحص أنواع لوحة التحكم الأوسع يبلغ عن 16 خطأ أنواع في اختبارات موجودة. يشمل فحص المتصفح تسمية القوائم والتبديل الموقّع بين المضيفين والأهداف غير المتاحة والأسماء غير الموثوقة وإعادة المحاولة بعد فشل الطلب وعدم تجاوز عرض الهاتف. لا يمنح موافقة للتثبيت الكامل أو الإنتاج.
