# هيكل المستودع

تصف هذه الخريطة شجرة المصدر الحاليّة. يحدّد [مرجع الحالة](status.ar.md) الإصدار العامّ والنسخة المثبّتة، ويوضّح [مرجع جاهزيّة النشر](deployment-readiness.ar.md) ما بقي من شروط التشغيل.

| المسار | المسؤوليّة |
|---|---|
| `src/control/` | المؤسسات والمشاريع والبيئات والصلاحيات والمفاتيح وواجهات الإدارة وAPI المتوافق مع Supabase وMCP |
| `src/gateway/` و`src/http/` | توجيه طلبات التطبيق والتحقق منها واحتسابها، وإيقاف الحركة ونقل الطلبات |
| `ui/` | لوحة Sbarbase المبنيّة بـ React وعناصر التحكم المشتركة وألوان الثيم ومساحات البيئة |
| `src/control/studio.ts` | وكيل Studio الأصليّ مع التحقق من الهويّة والجلسات والتبديل بين البيئات |
| `src/control/studio-workspace.ts` و`src/control/studio-identity.ts` | محدّد مساحة العمل الاختياريّ وهويّة آمنة للتبويب والرابط |
| `lab/` | أدوات المشغّل وتنسيق التشغيل والنسخ والاستعادة والترقيات المحميّة وبيئات الاختبار |
| `tests/` | اختبارات TypeScript، وتوجد اختبارات Python بجانب أدواتها داخل `lab/` |
| `deploy/` | حزم الحاويات وفحص المضيف وأدوات المشرف وTLS وأدوات التحقق المعزولة |
| `website/` | الموقع العامّ باللغتين والتوثيق المولّد ونسخ Markdown وتغذية سجلّ التغييرات وملفات اكتشاف المحتوى للوكلاء |
| `docs/explain/` و`docs/guides/` و`docs/reference/` | الشروح والإجراءات والمراجع الحاليّة الموجّهة للقارئ |
| `docs/decisions/` | قرارات التصميم وشروط مراجعتها |
| `docs/engineering/` و`docs/evidence/` | عقود الهندسة والمشاهدات المؤرّخة المرتبطة بمصدرها، بما فيها العمل غير المكتمل |
| `fragments/` و`.planning/` | أجزاء التطوير وسجلّات التخطيط، وليست متطلّبات لتثبيت المشغّل |

## المسارات الحاليّة والتجريبيّة

تختلف شروط قبول البنية المشتركة الموجودة عن أعمال التشغيل الأصليّ المخصّص التجريبيّة. وجود أداة أو اختبار في الشجرة لا يجعل المسار التجريبيّ جاهزًا للإنتاج. اقرأ شروط العمليّة قبل تنفيذها على موارد محفوظة. حُذفت أعداد الاختبارات القديمة وروابط المعاينات المؤقّتة من هذه الخريطة، وتبقى السجلّات المؤرّخة في دفتر الهندسة والأدلّة.

تصف [أهداف المشروع](../../PROJECT_GOAL.md) و[خطة المنتج](../engineering/plans/2026-10-03-product-and-portability-plan.md) و[سجلّ الأدلّة](../engineering/gauntlet-ledger.json) نطاق العمل الأوسع. ولا تحلّ هذه الملفات محلّ فحص المصدر والتثبيت الحاليين.

## الموادّ المحلّيّة والمولّدة

تحتوي `.lab/` و`.secrets/` حالة التثبيت الخاصّة. لا تنشرها ولا بيانات الاعتماد أو محتويات النسخ الاحتياطيّة. وتُولّد مجلدات الحزم وملفات الواجهة المبنيّة و`website/dist/` عند التثبيت والبناء.

`graft/` فهرس مصدر محلّيّ يتجاهله Git. شغّل `graft build` في نسخة جديدة عند الحاجة؛ الفهرس ليس من متطلّبات المنتج. اتّبع تعليمات وكلاء المستودع عند البحث عن الكود أو تعديله.

## التحقق

استخدم ملف قفل Bun المعتمد في المستودع وفحوص أنواع الواجهة والتحكم و`bun run build:ui` واختبارات Bun وPython المرتبطة بالتغيير. وتُفحص تغييرات التوثيق عبر `bun run build` و`bun test` داخل `website/`. لفحوص المتصفّح والحاويات الأصليّة متطلّبات عزل إضافيّة، وتبقى نتائجها مرتبطة بمصدرها ونطاقها.
