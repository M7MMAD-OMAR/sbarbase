# هيكل المستودع

آخر تحديث في 2026-10-06: نجح التحقق الكامل للشيفرة الحالية بنتيجة 1449 اختبارا، دون فشل أو أخطاء أو تحذيرات أو تجاوز، وقبلته مراجعة مستقلة. تشمل الإصلاحات إغلاق اتصالات SQLite واستجابات HTTPError، وملكية الملفات المؤقتة والتقاط تشخيصات الاختبارات المتوقعة. نجحت أيضا حالات تجهيز التشغيل الـ52، لكن تشغيل PostgreSQL الأصلي واستمرارية Cron وVault والاستعادة الفيزيائية لم تُقبل بعد. راجع [الحالة الحالية](status.ar.md) لنتائج CI وحدود الأدلة.

حصل نطاق public55 V3 المنفصل على قبول عملي: نجحت 25 حالة للمكوّن و30 للمضخة، وطابقت قراءة الملفات الأصلية الـ290 وقراءة الملفات الأربعة المضافة مع فحص صلاحياتها الأدلة، وحُذفت الحاويات الثلاث المعروفة دون موارد معلقة. وحصل نطاق بيانات المساعدة العامة BusyBox V8 على قبول عملي: أعاد Bash 5.3.3 وBusyBox 1.37.0 في المسارين المحددين بيانات الإصدار والمساعدة مع خروج بالرمز 0، وحُذفت حاويته الوحيدة. لا تقبل النتيجتان طلبا خاصا أو توقيت timeout وإشاراته أو مصدر الملف التنفيذي أو تشغيل المرشح أو استمرارية Vault وCron الباردة والدافئة أو الاستعادة الفيزيائية أو الإنتاج.

أعلنت تجربة نافذة التحذيرات V4 المحفوظة نجاح 1447 اختبارا عاديا، لكنها سجلت ستة ResourceWarnings وخرجت بالرمز 1، وكانت نافذة الملاحظة 839 لكل التحذيرات. تحمل ثلاثة سجلات النوع الدقيق sqlite3.Connection، وثلاثة اسم tempfile.py والسطر 484 مع مصدر NoneType. لا تحدد نافذة الملاحظة موضع التخصيص أو سببه؛ وما زالت أصول تحذيرات tempfile الثلاثة مجهولة. يلزم ربط المصدر والهوية والصلاحيات والمجموعة الكاملة من جديد، ثم CI للإصدار النهائي واستلام الخادم الخالي بتشغيل يدوي. تحتفظ نتائج CI والموقع للإيداع المنشور 0e745394 بنطاق ذلك الإيداع فقط.

يبني صباربيز طبقة إدارة وتشغيل فوق خدمات Supabase الأصلية. تساعد هذه الخريطة في العثور على الكود والأدلة والإجراءات؛ ولا تعني أن المشروع اجتاز قبول الإنتاج.

| `lab/native_startup_materials.py` | مواد التشغيل وتسليم وحدات التخزين المحفوظة |
| `deploy/verify/native_factory_startup_inspect.py` | منفذ التجهيز المحدود والقبول الأصلي الدقيق |

## مصادر إكمال طلبات SQL الخاصة

تحدد هذه المكونات العامة بروتوكول إكمال طلبات SQL الخاصة بحدود زمنية وحجمية واضحة. نجح التحقق الكامل للمصدر العام المجمّد، وعدد ملفاته 881، في 1504 اختبارا دون فشل أو أخطاء أو تحذيرات أو تجاوز؛ واجتازت النتيجة المراجعة العملية المستقلة والتحقق النهائي. راجع [أدلة اختبارات المصدر العامة](../evidence/private-pump-regression-2026-10-06.json). تغطي نتيجة CI الأخيرة، `6c86`، خط الأساس قبل إضافة هذه الملفات الأربعة؛ ولم تُشغّل أو تُقبل أدلة مصدر العميل الأصلي المثبت، وسلطة بدء الجلسة الخاصة، وإذن إعادة التشغيل المملوك، واستمرارية Cron وVault الباردة والدافئة، والاستعادة الكاملة.

| المصدر | المسؤولية |
|---|---|
| `deploy/verify/private_psql_producer.py` | ترميز الاستعلامات المحددة، وحماية مساحة الأسماء الحصرية، وتأطير التحكم، وحدود النقل |
| `deploy/verify/private_request_pump.py` | دورة طلب وإكمال محدودة، ونتائج محددة، ورفض الإكمال غير المؤكد |

## ما يرجع إليه العمل الحالي

تحدد [أهداف المشروع](../../PROJECT_GOAL.md) و[خطة المنتج](../engineering/plans/2026-10-03-product-and-portability-plan.md) و[طريقة التنفيذ والتحقق](../engineering/plans/2026-10-03-gauntlet-execution-method.md) اتجاه التطوير الحالي. ويفصل [عقد مكان التشغيل الأصلي](../engineering/plans/2026-10-03-native-placement-identity.md) البنية المستقلة التجريبية عن البنية المشتركة العاملة.

يربط [سجل الأدلة](../engineering/gauntlet-ledger.json) كل نتيجة بنسخة مصدرها ونطاقها، ويحتفظ بالتجارب الناجحة والفاشلة. بعض مساراته تشير إلى ملفات محلية لا توزّع مع المستودع؛ فلا تُعد أدلة عامة منشورة. وتبقى خطط سبتمبر ونقاط التحقق المؤرخة سجلات سابقة.

## التحقق من المصدر

من جذر المستودع، يعمل التحقق المعزول عبر Docker بهذا الأمر:

```sh
sh deploy/verify/run.sh
```

ينشئ الأمر حاوية تحقق مؤقتة بحدود موارد محددة، ويشغّل الفحوص دون اتصال بالشبكة، ويحفظ الأدلة في `.lab/` المستبعد من Git. تفاصيل النطاق في [دليل التحقق](../../deploy/verify/README.md). نجح تثبيت Docker في CI للإيداع `0e745394`، لكن مهمة قبول الخادم الخالي الاختيارية كانت متخطاة وتحتاج تشغيلا يدويا جديدا. يحتاج المصدر والوثائق بعد تعديلهما إلى فحوص جديدة؛ ولا تثبت هذه الفحوص الاستعادة الكاملة أو دعم كل الخوادم أو الجاهزية للإنتاج.

يحتوي `.lab/` و`.secrets/` على حالة محلية خاصة لا تدخل في نشر المصدر. كذلك تُولّد مجلدات الاعتماديات ومخرجات البناء أثناء العمل، ولا تحل محل ملفات إصدار يمكن إعادة بنائها والتحقق منها.
