# الحالة الحاليّة

آخر تحقق في 2026-11-13. يميّز هذا المرجع بين إصدار المصدر المنشور، والنسخة المثبّتة على الخادم، ونطاق اختبارات التشغيل.

## الإصدارات والعناوين

| العنصر | الحالة المرصودة |
|---|---|
| إصدار المصدر العامّ | [v0.12.2](https://github.com/M7MMAD-OMAR/sbarbase/releases/tag/v0.12.2)، عند الإيداع `b73d57a`، مع أرشيف المصدر وملف SHA256SUMS |
| تثبيت المالك | الإصدار الأساسيّ `0.11.2` مع تحديث خاصّ بلوحة الإدارة عند `53b43dafa761b1071aa4b36a3cfc92f87965392d`، وقد أكّدت آليّة التحديث نجاح تشغيله |
| موقع التوثيق | [base.sbarah.com](https://base.sbarah.com/)، بالعربيّة تحت `/docs/` وبالإنجليزية تحت `/en/docs/` |
| لوحة المالك | `https://sbarbase.sbarah.com`؛ ولكلّ تثبيت آخر عنوانه المضبوط |
| نسخة التطوير | قد تحتوي تغييرات غير منشورة. يُعرف محتواها من إيداع Git وملف الإصدار، ولا يدلّ رقمها وحده على النسخة المثبّتة |

أبقى تحديث لوحة الإدارة الخاصّ الحزم وصور الخدمات وتشغيل قاعدة البيانات كما كانت. ولم يتضمّن محوّل PGMQ أو حزم SDK الأحدث أو إضافات اكتشاف الميزات الموجودة في المصدر العامّ 0.12.2.

## ما تغيّر في لوحة الإدارة

- تميّز ألوان الأسطح بين مستويات الارتفاع، مع إبقاء مؤشر التركيز واضحًا عند استخدام لوحة المفاتيح.
- تبقى محدّدات مساحة العمل وأزرار تذييل القائمة ظاهرة أثناء تمرير روابط التنقّل. ويمكن اختيار المشروع والبيئة مباشرة.
- تُحمّل مساحة الاتصال عند فتحها، وتعرض خيارًا للاستعادة عند فشل التحميل. ويطلب النظام تأكيدًا قبل ترك مسوّدة دالة Edge غير منشورة.
- يبيّن عنوان التبويب اسم المشروع والبيئة. ويضيف Studio اسم عرض آمنًا في معامل `workspace` بالرابط، مع بقاء مضيف البيئة والتفويض الموقّع أساسًا للتوجيه والوصول.
- تتّبع قوائم الاختيار ألوان الواجهة في المتصفّحات التي تدعم تخصيصها، وتبقى القوائم الأصليّة متاحة في غيرها.

تجد التفاصيل في [تصميم اللوحة](console-design.ar.md) و[دليل Studio](../guides/studio.ar.md).

## ما جرى التحقق منه

نجحت اختبارات الحزمة باستخدام Bun وعددها 1610، واختبارات الترقية باستخدام Python وعددها 185. ونجحت كذلك فحوص الأنواع وبناء الواجهة والموقع وفحوص المتصفّح المعزولة للوحة وعددها 46. وشمل فحص منفصل صورة Studio المثبّتة على خادم المالك عبر عنوانها العامّ: اسم المشروع في التبويب، واسم العرض في الرابط، وتحميل ملفات الهويّة بعد التحقق من الصلاحيّة، واستمرارها بعد إعادة التحميل. وأعادت طلبات صحّة Auth وطلبات REST الحالة HTTP 200 في البيئات الأربع باستخدام مفاتيحها العامّة الموجودة.

أُنشئت نسخ احتياطيّة جديدة للبيئات الأربع والبيانات الوصفيّة المشتركة لـ Storage وحسابات الإدارة، وفُحصت بصمات الملفات وإمكان قراءة الأرشيفات. ولم تُجرَ استعادة كاملة منها في هذه الجولة. بقيت حاوية قاعدة البيانات وصور الخدمات العاملة كما كانت، وأُعيد إنشاء بعض حاويات الخدمات بالصور نفسها أثناء إعادة التشغيل. يسجّل [تقرير التحديث](../evidence/server-console-2026-11-13.json) هذا النطاق المحدّد.

لا تثبت هذه النتائج نجاح تثبيت جديد أو ترحيل صورة PostgreSQL أو استعادة خادم كامل أو سعة حمل محدّدة أو دعم جميع ميزات Supabase Cloud.

## العمل المتبقّي

- لم يكتمل ربط حفظ إعدادات SMTP في Studio الأصليّ. راجع [إعدادات المصادقة في لوحة Sbarbase](../guides/sign-in.ar.md)، ولا تعتمد على ظهور القيم في نموذج Studio لإثبات تطبيقها.
- يعلن المصدر العامّ 0.12.2 ترحيلًا يدويًّا لملكية PGMQ والبيانات الوصفيّة لنسخه الاحتياطيّة، ولذلك يرفضه محدّث 0.11.2 العاديّ. لا تحذف التصريح ولا تفرض التحديث. راجع [دليل الترقيات](../guides/upgrades.ar.md).
- تحتاج ترقية صور الخدمات، ومنها PostgreSQL 17.11، إلى فحوص مستقلّة للتوافق والترحيل والاستعادة. لم يعتمد تحديث اللوحة الخاصّ أيّ مجموعة صور مرشحة.
- يبقى `pg_stat_statements` محظورًا لحماية عزل البيئات. ولا تضيف صفحة Studio ذاتيّة الاستضافة الفوترة المستضافة أو فروع Git أو غيرها من الميزات غير المدعومة.

يوضّح [مرجع جاهزيّة النشر](deployment-readiness.ar.md) ما بقي من شروط القبول، ويبيّن [دليل الوكلاء](../guides/agents.ar.md) اختلاف توفّر واجهات API وMCP بين الإصدارات.
