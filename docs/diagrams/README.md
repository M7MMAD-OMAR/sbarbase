# Diagrams

Every diagram exists twice: `name.svg` with English labels for the English pages, and `name.ar.svg` with Arabic labels, laid out right to left, for the Arabic pages. Both are generated by [build.py](build.py) from one description, so edit the script, never the SVG files, and regenerate:

```bash
/usr/bin/python3 docs/diagrams/build.py
```

Each file is self-contained: a solid paper background so it reads on a dark page, system fonts only (`system-ui, sans-serif`), no external fonts, images or scripts, and a `<title>` and `<desc>` that state the claim in words. The colours follow the website: coral marks a shared component, and therefore a shared failure boundary; teal marks something that exists once per environment; mustard is an environment's database; a dashed lilac outline marks something planned and not built.

To check a diagram after editing, render both variants with a headless browser (for example `chromium --headless --screenshot --window-size=<viewBox width>,<height> file://...svg`) and look at the result: no label may leave its box, and the Arabic variant must read right to left. Keep font sizes between 11 and 16 and leave slack in every box, because viewers whose system font is wider than yours will see wider text.
