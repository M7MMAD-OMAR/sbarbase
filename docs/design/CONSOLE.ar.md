# المواصفات البصرية للوحة الإدارة

المرجع: `console-concept.png`، صورة ولّدتها أداة الصور المدمجة في 2026-09-20.
النطاق: واجهة طبقة المنصة وحدها. سُحب هدف مطابقة نظام التصميم مع Studio: كل بيئة
يديرها Studio الأصلي (upstream)، وليس لنا أن نضع مواصفاته
([مواصفات الدمج](../engineering/STUDIO-INTEGRATION.md)).

الواجهة الأساسية: الشريط الجانبي، ومحدد المنظمة، وجدول المشاريع، ونموذج الإنشاء.
الإضافات المطلوبة ضمن النظام نفسه: الدخول بكلمة مرور، وحالات الفراغ والخطأ والتحميل،
وقائمة بيئات المشروع، وحالة التجهيز، وتفاصيل الاتصال، وإصدار المفاتيح وإلغاؤها.
لا مقاييس مختلقة، ولا توقعات موارد، ولا روابط تنقل إلى ما لا وجود له.

الرموز اللونية والقياسات: هذه رموز طبقة المنصة الخاصة، لا رموز Studio. لكل رمز قيمة فاتحة
وقيمة داكنة: الفاتحة هي الافتراضية، والمجموعة الداكنة تُطبَّق حسب تفضيل نظام التشغيل أو
المتصفح، والاختيار الصريح يتقدم على الاثنين. الخلفية #171717، والشريط الجانبي #1c1c1c، والسطح #202020، والحدود #303030،
والنص #ededed، والنص الثانوي #a0a0a0، ولون التمييز #3ecf8e مع نص داكن. تعبئة مسطحة محايدة،
وأي إضاءة أو حبيبات في الصورة المولّدة ليست من أصول الإنتاج. لا أصول واجهة نقطية.
الخطوط: خط النظام بلا زوائد، 14px للعناصر والنص، و34px للعنوان، و12px للبيانات الوصفية، وخط ثابت العرض للمعرّفات.
الشريط الجانبي 268px على الحاسوب، وحشو المحتوى 40px، والترويسة 64px، والعناصر 40px،
والصفوف 92px. أبعاد المرجع الأصلية: 1586 x 992. أيقونات Lucide المحددة
بقياس 18px وخط 1.75px؛ بلا شعار مصوّر، والاسم مكتوب نصًا فقط.

توزيع مكوّنات React: جلسة التطبيق وتخطيطه، والدخول، والمشاريع، والبيئات،
والاتصال، ومكوّنات قابلة لإعادة الاستخدام لنموذج الإنشاء والحالة والخطأ. يبني Vite الأصول،
ويقدّمها Bun مع API من المصدر نفسه. النماذج والقوائم والأزرار أصلية من المتصفح، ونماذج
الإنشاء مضمّنة في الصفحة لتجنّب مصائد التركيز في النوافذ الحوارية. لا يُحفظ أي سر ولا جلسة Auth
في تخزين المتصفح. يظهر مفتاح المشروع الخام مرة واحدة، ويُمسح عند الانتقال.

يقدّم التصميم المولّد أسماء ومعرّفات قصيرة كأمثلة. أما الصفوف والأسماء والمعرّفات والأعداد
والصلاحيات والحالات فتأتي من بيانات API الحقيقية. الفروق المقصودة: تكديس العناصر
تحت عرض 720px، وإشعارات تشغيلية فقط للمهام المعلّقة أو الفاشلة فعلًا، والمعرّفات الكاملة
متاحة في تفاصيل الاتصال، ونماذج الإنشاء والمفاتيح مضمّنة في الصفحة.
نصوص المرجع هي: الاسم المكتوب نصًا، وOrganization، وProjects، وLocal installation،
وSign out، وYour projects، وorganized in one place.، وNew project، وSearch projects،
وProject، وProject ID، وعدد المشاريع الفعلي. وباقي نصوص الواجهات وظيفية.

ملخص طلب التوليد: لوحة إدارة صباربيز داكنة كاملة بأسلوب Supabase بقياس 1440 x 900، فيها شريط جانبي
ومحدد منظمة، وعنوان Projects مع بحث، وجدول مشاريع من صفين، وزر
New project أخضر، دون مقاييس أو رسوم بيانية أو واجهة ترويجية أو رسوم توضيحية. أعادت الأداة صورة بقياس 1586 x 992.

## التسليم إلى Studio

طبقة المنصة لا تدير البيئة. هي تربط إلى Studio الخاص بتلك البيئة،
أي تطبيق الأصل نفسه، مقدَّمًا على مسار خاص به يتطلب مصادقة
([مواصفات الدمج](../engineering/STUDIO-INTEGRATION.md)، القسمان 4 و5).
كل ما داخل البيئة، من الجداول وSQL إلى مستخدمي Auth
وإعداداته، يخص Studio وتصميمه الأصلي، ولا تحدد هذه الوثيقة شيئًا منه.

واجهة الاتصال تعرض بالفعل الخدمات التي تتيحها البيئة، ويُضاف مدخل Studio
إلى تلك القائمة، فيصل إليه الشخص بالطريقة التي يصل بها إلى
API، لا عبر تنقل ثانٍ من صنعنا.
